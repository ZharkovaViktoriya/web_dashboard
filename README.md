# Антистресс-центр

Статический проект на HTML, CSS и vanilla JavaScript с ES-модулями. React, npm и сборка не нужны.

## Запуск

Из папки проекта выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Виджеты и API

Панель выбрана в теме «Антистресс-центр»: карточки можно добавлять, сворачивать и удалять. Повторное добавление того же типа блокируется понятным уведомлением.

- Список дел: добавление непустой задачи, отметка выполнения и удаление; задачи сохраняются после перезагрузки.
- Судоку: новая сетка загружается из Dosuku Sudoku API (https://sudoku-api.vercel.app/), затем отображается как статичная SVG-картинка в оформлении дашборда. Это не интерактивная игра; кнопка ↻ в заголовке получает новую головоломку.
- Погода: Open-Meteo (геокодирование и прогноз), поиск города и переключение °C/°F. API не требует ключа: https://open-meteo.com/en/docs
- Музыка: список ambient-радиостанций из отдельного сервиса Radio Browser API: https://api.radio-browser.info/ (без секретного ключа). Можно воспроизвести поток, если выбранная станция доступна.

Сетевые виджеты показывают состояние загрузки, результат либо сообщение об ошибке и способ повторить запрос: для погоды и музыки — кнопка «Повторить», для судоку — кнопка ↻ в заголовке. Сбой одного запроса не блокирует другие карточки. Запросы отменяются при удалении карточки.
- Раскраска и антистресс-кликер работают локально.
- Виджеты и задачи сохраняются в `localStorage`. После перезагрузки классы виджетов создаются заново по сохранённым типам, погода, музыка и судоку загружаются заново из внешних API.
- Если `localStorage` недоступен или повреждён, панель продолжает работать без сохранения. При ошибке внешнего API показывается сообщение, а актуальные данные не подменяются демонстрационными.

## Файлы

- `index.html` — разметка панели и меню добавления виджетов.
- `styles.css` — стили и адаптивность.
- `js/main.js` — инициализация панели, интерактивность виджетов, задачи и API-состояния.
- `js/api.js` — запросы к API.
- `js/storage.js` — безопасная загрузка и сохранение состояния.
- `js/Dashboard.js` — жизненный цикл набора виджетов.
- `js/UIComponent.js` — базовый класс карточки.
- `js/ToDoWidget.js` — список дел, наследующий `UIComponent`.
- `js/widgets.js` — метаданные и разметка виджетов.
- `js/audio.js` — мягкий звук клика.


## Последние изменения

- Судоку загружается из Dosuku API и оформляется как статичное изображение SVG в стиле дашборда. Кнопка ↻ в шапке карточки загружает новую головоломку; отдельной кнопки внутри изображения нет.
- Удалены второстепенные мотивационные тексты, подписи над карточками и кнопки «Подробнее».
- Заголовки оформлены пиксельным шрифтом Press Start 2P.
- Карточки больше не растягиваются по высоте до размера соседних карточек.

Для получения нового судоку требуется интернет-соединение и доступность Dosuku API. Если сервис недоступен, в карточке появится сообщение об ошибке; повторный запрос запускается кнопкой ↻.

## Как проверить требования задания

1. Добавь «Список дел», создай задачу, отметь её выполненной и удали; обнови страницу и проверь сохранение.
2. Добавь «Погода» и «Звуки»: дождись результата либо ошибки, затем нажми «Повторить». Для судоку проверь загрузку изображения и кнопку ↻.
3. Сверни и разверни карточку, удали и добавь её снова. Повторное добавление уже существующего типа должно показать уведомление.
4. Добавь и удали несколько разных карточек подряд: обработчик каждого действия должен срабатывать один раз.
5. Проверь адаптивность на узком экране. При отсутствии сети сетевые виджеты должны показывать ошибку, а не придумывать актуальные данные.

## Использование нейросети

Проект дорабатывался с помощью ChatGPT: каркас, ES-модули и классы, подключение API, сохранение состояния, обработка ошибок и адаптивная вёрстка. Полезные промпты: «Добавь независимый виджет погоды через Open-Meteo с состояниями загрузки/ошибки и повтором»; «Проверь восстановление карточек и задач из localStorage»; «Проверь, что после многократного добавления и удаления виджета обработчики не дублируются».
